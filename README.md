# 2027 CS/EE 研究生申请导航（本地网页）

可离线打开、可打包分享的交互界面，覆盖：

- **香港本地**（与美国分区显示）
- **香港院校大陆校区**（HKUST广州、CUHK深圳、BNBU珠海等）
- **美国**（CS/EE 相关约 50+ 所，偏 QS/常用申请名单）
- **新加坡 / 日本 / 韩国**

默认筛选：**PhD**。可用顶部按钮切换为硕士。

## 如何打开

1. 用 **Edge / Chrome** 双击打开 `index.html`  
2. 或把整个 `phd-2027-admissions` 文件夹压缩发给同学，对方解压后同样打开 `index.html`

> 必须保持同目录有：`index.html`、`styles.css`、`app.js`、`data.js`、`faculty.js`


## 界面功能

- 按 **学位 / 地区 / 资助类型** 筛选  
- 关键词搜索（学校、HKPFS、AI…）  
- 按截止日期 / 地区 / 学校 / 资助排序  
- 「仅高置信度」过滤  
- 详情区含：**截止与入学、Funding、招生要求、语言、注册网站、备注**  
- **导出当前筛选为 CSV**

## 重要说明

- 截止日期会变动，**提交前务必点「打开官方申请页」复核**  
- 美国 PhD 通常「录取≈全奖」；美国授课型硕士多为自费（界面已分开）  
- 香港 HKPFS 与常规 PGS 是两条线：先 RGC 再学校  
- 日本强依赖导师内诺；韩国国际生窗口有时极短（如 SNU）

## 导师 / 图形学

- `faculty.js`：各校代表性导师（含主页、研究方向）
- 界面中**加粗高亮**的研究方向 = 图形学相关（Graphics / Rendering / Geometry / Animation / Simulation / 3DGS / NeRF 等）
- 勾选「仅有图形学相关导师的学校」可快速筛选
- 重新生成：`py -3 build_faculty.py`

注意：导师库为申请导向抽样，**不是**全系完整花名册；套磁前请再核对官网是否在招。
